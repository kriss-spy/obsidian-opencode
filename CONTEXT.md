# Obsidian OpenCode

An Obsidian plugin that makes the OpenCode CLI available inside a vault. It exists to support dependable, uninterrupted coding sessions without leaving Obsidian.

## Language

**OpenCode workspace integration**:
A focused embedding of the OpenCode CLI in Obsidian, including the terminal, vault context, and session lifecycle. It is not a general AI workspace or a knowledge-management product.
_Avoid_: AI coding workspace, AI-to-vault knowledge workflow

**Platform reliability**:
Linux stability is preserved while Windows becomes a supported platform; macOS remains experimental, with existing defects fixed as capacity allows.
_Avoid_: equal support across all desktop platforms
