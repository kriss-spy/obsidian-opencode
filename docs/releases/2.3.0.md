# OpenCode 2.3.0

Add note context and navigate terminal output more easily inside Obsidian.

- Drop folders from the file explorer to paste their vault-relative paths with a trailing slash. Folder names with spaces and Unicode are preserved; file drops keep their existing line mentions.
- Use **Add active line or selection to terminal** to reference a note line or selected range. ([#46](https://github.com/kriss-spy/obsidian-opencode/issues/46))
- Open HTTP(S) links in your browser and vault note paths in Obsidian, including references split across multiple terminal rows and table cells. Hover underlines the complete target within its text bounds. Ctrl/Cmd-click works while OpenCode handles terminal mouse input. ([#62](https://github.com/kriss-spy/obsidian-opencode/issues/62))
- Optionally use Shift+Enter for a newline; changing the setting takes effect immediately.
- Prevent Ctrl+Z from suspending and freezing embedded OpenCode, while preserving configured undo bindings.
- Focus terminal input when opening it, retain completed-task touched-note warnings when OpenCode V2 reports an empty diff, and use the OpenCode ribbon logo. ([#57](https://github.com/kriss-spy/obsidian-opencode/issues/57), [#21](https://github.com/kriss-spy/obsidian-opencode/issues/21), [#63](https://github.com/kriss-spy/obsidian-opencode/issues/63))

Requires Obsidian 1.7.2 or later on desktop. macOS remains experimental.

See [the full changelog](https://github.com/kriss-spy/obsidian-opencode/blob/2.3.0/CHANGELOG.md) for details.
