# OpenCode 2.4.0

- Save resumable OpenCode session links in notes. Copy the current session with the command palette or copy a selected session from the conversations panel (#69).
- Open full Markdown paths outside the vault in Obsidian 1.14.2 and newer. Links retain line and column locations. Earlier Obsidian versions continue to support vault note links (#66).
- Validate the exact packaged plugin files across Linux, Windows, and macOS before publication. Required Linux workflows now cover session links, focus, Ctrl+Z, and file/folder mentions.
- Add development commands for terminal buffer capture, fixture replay, verification, and installation into an explicit vault with backups.

Session links require the referenced session and working directory on the target machine. Copying the live terminal session requires a compatible OpenCode V2 CLI; older CLIs can use the conversations panel.

macOS remains experimental. See the [release verification record](https://github.com/kriss-spy/obsidian-opencode/blob/main/docs/releases/2.4.0-checks.md) for automated evidence and manual coverage still pending.
