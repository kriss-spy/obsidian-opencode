Use Obsidian's `createSpan` for underlines and accurately type receiver-independent snapshot callbacks. Remove unnecessary match-index assertions while supporting the repository's TypeScript 4.7 compiler.
- Load Electron only when opening an external link, using Node's `createRequire`, with `shell` retained as the call receiver.
- Type mocked callbacks and arguments instead of suppressing unsafe/unbound-method findings.
