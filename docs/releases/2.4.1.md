# OpenCode 2.4.1

- Prevent duplicate Chinese and Japanese composition text when switching Fcitx5 input methods with Super+Space (#86). Captured Fedora event replays pass; native confirmation of the patched build remains pending.
- Restore Windows terminal graphics negotiation and native picker clicks with packaged ConPTY (#83). Windows requires Windows 10 version 1903 or newer.
- Save resumable OpenCode session links in notes. Copy the current session from the command palette or a selected session from the conversations panel (#69).
- Open full Markdown paths outside the vault on Obsidian 1.14.2 and newer, preserving line and column locations (#66).

This release includes the previously unpublished 2.4.0 work. Session links require the referenced session and working directory on the target machine. Copying a live terminal session requires a compatible OpenCode V2 CLI.

Relative note paths resolve from the vault root and require an exact path. External files require a full native path, such as `/home/me/project/My notes/README.md` on Linux or `C:\Projects\My notes\README.md` on Windows. Spaces and `:line:column` locations are supported. Partial paths do not search subfolders. See [terminal link examples](https://github.com/kriss-spy/obsidian-opencode/blob/2.4.1/docs/terminal-links.md).

Known issue: #81 reports inconsistent note-path hover detection and remains unresolved. macOS remains experimental.

See the [release verification record](https://github.com/kriss-spy/obsidian-opencode/blob/2.4.1/docs/releases/2.4.1-checks.md) for evidence and pending checks.
