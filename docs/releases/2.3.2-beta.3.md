# OpenCode 2.3.2-beta.3

Windows testing prerelease for the terminal hover freeze fix (#70).

- Cache logical terminal lines and bound TUI wrap reconstruction after ConPTY reflow.
- Fix touched-note status when macOS resolves the vault through a filesystem alias.
- Require Linux, Windows, and macOS app and real OpenCode checks before release publication.

To test, install all three assets (`main.js`, `manifest.json`, and `styles.css`) together in your vault's `.obsidian/plugins/opencode/` directory while Obsidian is closed, then reopen it. BRAT can also install the specific `2.3.2-beta.3` release from `kriss-spy/obsidian-opencode`.

On Windows, open the terminal at about 109 × 81 cells, resize the pane or switch windows and return, move the pointer over several terminal rows, then type. Check that typing remains immediate and links still open with Ctrl+click. Try the current stable Obsidian and your early-access build if available.

This prerelease contains the #70 fix and CI hardening. The separate pending terminal-maximize and numeric URL continuation changes are excluded. The stable 2.3.1 release remains unchanged.
