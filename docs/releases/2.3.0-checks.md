# 2.3.0 release preparation

Prepared on 2026-10-06. Release tag: `2.3.0` (no `v` prefix). Version metadata and lockfile agree. Minimum Obsidian version remains 1.7.2; the plugin remains desktop-only. No release tag or GitHub release has been created.

## Candidate checks

- Production TypeScript/esbuild build passed; artifacts contain no inline source map.
- Unit suite: 335 passed, 5 platform-only skipped.
- Full Linux app suite: 62 passed, all eight spec files green, using Obsidian app/installer 1.12.7 and installed OpenCode 2.0.22 with `OPENCODE_REAL_E2E=1`.
- The first full run had two intermittent hover precondition failures. All 27 link tests then passed standalone. The final full run passed after waiting for stable terminal fixture geometry before writing and locating cells. Every click, navigation, underline, containment, and PTY-input assertion remains enabled; failure diagnostics include xterm mouse/provider state.
- Follow-up review regressions cover complete punctuation-bearing note paths with basename decoys and independent prose references, plus selection-clearing clicks through textual and OSC 8 activation. All 29 link app cases passed; the two new cases also passed a focused run after the final fixture adjustment. Standards and Spec reviews cleared the final fixes.
- GUI checks were serialized under `/tmp/obsidian-opencode-real-app.lock` in isolated vaults/profiles. The user's active app was not used for tests or reloaded, and no model prompt was submitted.

## Static review and platform limits

The optional local automated-review mirror **failed: 103 ESLint errors**, versus 19 in the 2.2.0 baseline under the same toolchain. Of the current findings, 89 are in mocked unit tests and 14 are in production code (intentional control-character filters/ANSI recognition, legacy IME and leaf-identity APIs, lazy Electron loading, and typing/style cleanup). Standards review found no current correctness defect in these findings. This is not a clean automated-review score. Raw reports accompany the local release bundle; a separate lint-cleanup change is needed to claim a clean score.

Fresh Windows CI is required before publishing. Native Windows real-CLI, WSL2/X410, and macOS checks have not been repeated for this release; macOS remains experimental. Linux results do not establish those platform results.
